# 跳跳桌面招手与迎宾互动方案

买家把跳跳放在工作室展示，朋友伸手就能让它回应。先让买家的专属外观和动作值得拍，再让来客用一个自然动作参与。以下动作、识别阈值和验收目标均为设计草案。

| 场景 | 触发与表现 | 结束与抢占 |
|---|---|---|
| 桌面待机 | 足端维持支撑，机身留在原地。可从每 30–60 秒一次开始试调，单螯缓慢招两下，如招财猫；其余时间静止 | 有来客伸手时平滑收势。提供静音静止模式，停止指令优先 |
| 伸手问候 | 单人进入划定区域，肩、肘、腕方向一致，单手前伸保持约半秒。跳跳举起张开的螯，在固定位置做握手状 | 不追手、不夹握。停留后收回，等来客收手才允许再次触发 |
| 专属亮相 | 主人按键触发自己的配色、徽记和招牌动作，如单螯敬礼、抱拳拜年或斜举螯定格 | 桌面模式只做原地动作；移动登场另在地面模式验证。留两秒定格供合影 |

**实施次序**

1. 先在 Windows 隔离环境加载官方模型、推进物理并出图，留存命令及版本。
2. 手动按键分别触发左右螯。按模型关节名核对方向、限位、接触和支撑；以连续物理回放确认机身不漂移、不倾倒。连续十轮招手均稳定后，再加入等待、抢占和复位。
3. 先用电脑摄像头和一名自愿参与者测试伸手、挥手、收手。单人固定区域内按肩宽归一化关键点，低置信度或多人时保持等待。记录每类各 20 次的触发、漏触发和延迟，另录普通走过和拿手机各 10 次检查误触发。
4. 同屏录制人的动作与仿真回应，清楚标出按键或摄像头触发。制作约 25 秒参赛草稿：待机招手、来客伸手、螯回应、主人敬礼定格。发布时使用当轮官方规则。

**真机前提**：先在地面测试中止、限位、支撑和失联静止，再验证桌面边缘隔离。第一版为隔空握手，真实接触需单独验证力与夹点。仿真和摄像头原型均不能证明真机接触安全。
